# CB-MDTMv2

CB-MDTMv2 projesi, canlı izleme, TPT ve Esogü DT Tool (STLC Manager) ve Sistem ayarlarını içermektedir.

## Proje Yapısı

```
CB-MDTMv2/
├── frontend/              # React/Vite frontend uygulaması
│   ├── src/               # Kaynak kodlar
│   ├── public/            # Statik dosyalar
│   └── package.json       # Frontend bağımlılıkları
├── backend/               # Backend modülleri
│   └── stlc-manager/      # STLC Manager backend modülü
└── README.md
```

## Kurulum

### Frontend

```bash
cd frontend
npm install
```

### Backend

Backend modülleri için ilgili klasöre gidin ve kurulum talimatlarını takip edin:

```bash
cd backend/stlc-manager
# STLC Manager backend kurulum talimatları
```

## Çalıştırma

### Frontend

```bash
cd frontend
npm run dev
```

### Backend

Her backend modülü kendi çalıştırma talimatlarına sahiptir. İlgili modül klasörüne bakın.

## Modüller

- **Canlı İzleme**: Tamamlandı (frontend)
- **TPT Modülü**: Tamamlandı (frontend)
- **STLC Manager**: Tamamlandı (backend & frontend)

# Cloud-Based-Digital-Twin-Monitoring
Rather than building another Digital Twin, CB-MDTM federates the outputs of existing tools — robot simulation, trajectory planning, predictive maintenance, and software verification — under one unified dashboard with consistent data semantics, traceable session lifecycle, and evidence-backed verification.
